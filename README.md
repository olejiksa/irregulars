# Irregulars

The iOS/iPadOS app
- 269 irregular verbs with transcription, voice acting, translation, examples of use in the English sentences
- A set of customizable widgets for the Home Screen or Today View created using the latest features of iOS 14 allows you to memorize irregular verbs even if you are lazy or just have no time to open the app itself
- Spotlight, Dynamic Type. iPad compatibility is not just for show. Higher information density, more comfortable interface. Support for Apple multitasking technologies: Split View and Slide Over. More options for a large screen. Dark theme
